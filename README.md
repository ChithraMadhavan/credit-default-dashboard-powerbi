# Credit Card Default Analysis

## Overview

This project analyzes customer credit card payment behavior and default risk using the UCI Default of Credit Card Clients dataset. The analysis was performed using Excel and Power BI to identify customer risk patterns, payment behavior, and financial trends.

## Dataset

* Source: UCI Machine Learning Repository
* Records: 30,000 customers
* Domain: Banking and Financial Analytics

## Tools Used

* Microsoft Excel
* Microsoft Power BI

## Key Tasks

* Data Cleaning and Transformation
* Exploratory Data Analysis (EDA)
* Pivot Table Analysis
* KPI Development
* Interactive Dashboard Design

## Dashboard Features

### KPIs

* Total Customers
* Average Credit Limit
* Average Outstanding Balance

### Visualizations

* Default Status Distribution
* Default by Education Status
* Customer Distribution by Age Group
* Payment Behaviour Analysis
* Outstanding Balance by Risk Category

### Filters

* Education Status
* Age Group
* Payment Behaviour
* Risk Category
* Default Status

## Key Insights

* Customer payment behavior influences default risk.
* Higher outstanding balances are associated with higher risk categories.
* Education and age groups show different default patterns.
* Credit limits vary across customer segments.
